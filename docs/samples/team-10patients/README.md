# 팀 샘플 10명 · 시드 변환 보고서

**상태**: 시연용 모의 데이터 · **작성일**: 2026-11-27 · **원본**: [source.md](source.md) · **결과**: [`data/seed/demo_seed.json`](../../../data/seed/demo_seed.json) · **모델**: [데이터 모델](../../data-model.md)

팀 샘플 "NutriSight 가상 환자 10명과 7일 식사 기록 최종본"(11/23~11/29, 210끼)을 [데이터 모델](../../data-model.md)과 2026-11-27 결정에 맞춰 시드 JSON으로 바꿨다. 시연 역할은 [시연 환자 구성](../README.md)에 있다.

## 시드 파일 구성

| 키 | 건수 | 내용 |
| --- | ---: | --- |
| `patients` | 10 | 기본 정보, 병실, 기저질환, 만성콩팥병 여부 |
| `patient_weights` | 20 | 환자별 체중 2건 (D-38 · D-7) |
| `patient_targets` | 10 | 하루 에너지·단백질 목표 (진료팀 설정, D-7부터) |
| `patient_assessments` | 43 | 영양위험 선별, 식욕·식사 보조, 삼킴·씹기, 욕창, 재급식 위험 |
| `meal_plans` | 24 | D-7~D의 아침·점심·저녁. 끼니마다 6칸(`slots`) |
| `meal_orders` | 240 | 환자 10명 × 24끼. 칸별 섭취(`slot_intakes`)와 끼니 섭취량 포함 |

- **날짜**: 모든 날짜는 시연일(D=0) 기준 상대값(`day_offset`, `*_offset`)이다. 샘플 11/23~11/29는 D-7~D-1, 시연일 D는 배식 계획과 발주만 있고 끼니는 시연 중 업로드한다. 시드를 넣는 스크립트가 시연일을 받아 실제 날짜로 바꾼다.
- **나이**: 상대 날짜에 맞춰 생년 대신 시연일 기준 나이(`age_at_d0`)를 넣었다. 시드 스크립트가 `birth_year`로 바꾼다.
- **사진**: 기록된 끼니는 사진 파일 없이 모의 추정(`estimate_basis = "mock"`)이다.

- **NS09**: D-7~D-3에 50% 이하 5일 연속으로 경고다. D-2부터 회복했지만 최근 7일 안에 연속 5일이 있어 경고가 유지된다.

## 남은 확인

- 추가 칸 메뉴·영양값과 배식량은 근사 모의값이다. 팀이 실측한 값이 생기면 바꾼다.
- 원본에 없는 "시연일 D 배식 계획"은 변환 때 정했다. 팀 메뉴로 바꿔도 된다.
- NS09의 경고가 회복 후에도 유지되는 규칙(최근 7일 안의 연속 5일)이 의도와 맞는지 팀에서 확인한다.
