# NutriSight 가상 환자 10명과 7일 식사 기록 최종본

**팀** show me the plate · **기간** 2026-11-23~2026-11-29 · **대상** 가상 환자 10명 · **예정 기록** 210끼

## 시연 범위

모의 진료팀이 해당 끼니에 **병원 일반식 상식(밥)**을 처방한 환자를 대상으로 한다. 기저질환이 있는 경우에도 등록 여부는 해당 끼니의 식이 처방으로 판단한다. 같은 날짜와 끼니에는 10명 모두에게 동일한 밥·주찬·부찬과 표준 1인분을 배식한 것으로 설정했다. 촬영과 섭취량 집계는 **아침·점심·저녁 병원식 세 끼**가 범위다. [아주대학교병원 환자식 안내](https://hosp.ajoumc.or.kr/conts/101011001000000.do)

환자 정보, 식이 처방, 배식 영양량, 섭취율, 사진 상태는 시연용 가상값이다. NS07의 등록 정보와 첫날 메뉴별 섭취율은 팀의 가상 환자 샘플을 반영했다.

환자 선택 후 `meal_records`, `daily_summaries`, `weekly_summaries`를 `patient_id`로 조회한다. 메뉴 이름과 표준 배식 영양량은 끼니의 `meal_plan_id`로 배식표를 연결해 가져온다. 사진 상태와 직원 확인 여부는 `evidence`에 있다. 샘플에는 가상 사진 상태가 있고 실제 사진 파일은 연결되어 있지 않다.

**NS07 연결 예시.** 82세 여성, 현재 체중 50.0 kg, 하루 목표 1,500 kcal·단백질 55 g이다. 첫날 세 끼는 `NS07`에 연결된다. `NS07_2026-11-23_breakfast`의 섭취율은 쌀밥 70%, 달걀찜 100%, 애호박볶음 0%다. 아침은 **410.0 kcal·21.5 g**, 첫날 세 끼 합계는 **1,177.0 kcal·58.6 g**이다.
