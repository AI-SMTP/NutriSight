# 풀무원 주간 식단 · 시드 반영 보고서

**상태**: 시연용 모의 데이터 · **작성일**: 2026-11-27 · **원본**: [source.md](source.md) · **결과**: [`data/seed/demo_seed.json`](../../../data/seed/demo_seed.json) · **모델**: [데이터 모델](../../data-model.md)

팀이 정리한 "NutriSight 모의 환자 10명 · 풀무원 주간 식단"([source.md](source.md))의 배식 계획을 시드의 D-7~D-1에 옮겼다. 원본 식단은 [풀무원 요양시설용 식단](https://pulstory.pulmuone.com/bbs/board.php?bo_table=m11_01&wr_id=587) 2025-12-01~12-07이다. 시연 역할은 [시연 환자 구성](../README.md)에 있다.

## 바꾼 것과 그대로 둔 것

| 항목 | 처리 |
| --- | --- |
| D-7~D-1 배식 계획 21끼 | 문서의 메뉴·배식량·칸별 열량·단백질로 교체. 문서 날짜 11/30~12/06 → D-7~D-1 |
| D 배식 계획 3끼, D 발주 30건 | 그대로 (문서에 D가 없음) |
| 환자 · 체중 · 목표 · 평가 | 그대로 (문서 값과 같음을 확인) |
| 발주 상태 · 칸별 섭취율 | 그대로 (문서 값과 같음을 확인). D-2 점심 부찬 2칸만 미배식으로 빠짐 |
| 끼니 섭취량 (`energy_kcal_est`, `protein_g_est`) | 새 배식 계획으로 다시 계산 (소수 첫째 자리). 문서 값과 ±0.05 안에서 일치 |
| `position` | 데이터 모델 표기로 맞춤 (`윗줄 1` → `윗줄 1 (왼쪽 끝)`, `윗줄 4` → `윗줄 4 (오른쪽 끝)`). D 포함 24끼 모두 |
| NS07 D-7 세 끼의 `source_note` | 새 메뉴 이름으로 고침 |
| 날짜 형식 | 상대 날짜(`day_offset`) 그대로. 문서의 절대 날짜·`birth_year`는 쓰지 않음 |

- **칸별 영양값은 추정값이다.** 원본은 끼니별 열량·단백질 합계만 제공한다. 문서 작성자가 음식 유형을 바탕으로 합계를 칸에 나눴고, 21끼 모두 칸 합계가 원본 합계와 같다.
- **2/3 밥**: 원본의 "미호현미밥2/3"(D-7 점심, D-1 점심)은 140 g으로 둔다.

## 미배식 칸

D-2 점심(원본 2025-12-06 토요일 점심)은 원본 메뉴가 다섯 가지다. 배추김치를 김치 칸으로 옮기고 부찬 2(`slot_5`)를 미배식으로 둔다. [데이터 모델](../../data-model.md)의 미배식 칸 규칙을 따른다.

- `meal_plan_slots`: `menu_name = null`, `served_g = 0`, `energy_kcal = 0`, `protein_g = 0`
- `slot_intakes`: 이 칸의 행을 만들지 않는다. 그래서 칸별 섭취 행이 1,236건에서 1,226건이 된다 (D-2 점심 발주 10건 × 1칸)

## 시연 역할에 미치는 영향

섭취율은 그대로지만 하루 제공량이 약 2,200 kcal에서 약 1,700 kcal로 줄어 목표 대비 비율이 낮아진다. D-1 판정(7일 평균 75% 미만이면 주의, 50% 이하 연속 5일이면 경고)은 다음과 같다. 문서의 7일 요약과 같다.

- NS01 D-3 점심은 금식, NS08 D-5 저녁·NS09 D-1 저녁·NS10 D-4 점심은 미기록이라 기록된 끼니로 하루를 환산했다.
- **시연 중 전환 (제안)**: NS05는 D에 한 끼를 올리면 평가 기간이 D-6~D로 바뀐다. D 점심(773 kcal)을 60% 미만으로 먹은 사진을 올리면 그날이 79% 미만으로 환산되어 7일 평균이 75% 아래로 내려가고, 정상에서 주의로 바뀐다.
- D의 메뉴(하루 약 2,200 kcal)는 D-7~D-1(약 1,700 kcal)보다 제공량이 많다. 팀이 D 메뉴를 실제 모의 식판에 맞춰 바꾸면 위 전환 기준도 다시 계산한다.

## 남은 확인

- 칸별 영양값의 타당성: D-1 아침 순살삼치무조림(90 g, 단백질 3.4 g)은 원본 끼니 합계(단백질 10 g)부터 확인이 필요하다. 소이로운장조림(D-3 아침, 6.2 g)과 오징어우동볶음(D-7 점심, 6.7 g)도 낮다.
- 2/3 밥(140 g, 205 kcal)은 210 g 밥(270 kcal)보다 g당 열량이 높다.
- 평가 메모의 날짜(NS05 "11/26 점심", NS06 "11/24·11/27", NS07 "11/23 아침")는 옛 샘플 날짜다. 상대 날짜로는 같은 날(D-4, D-6·D-3, D-7)을 가리킨다.
