## 첫날 요약

| 항목 | 값 |
| --- | --- |
| 기록된 끼니 | 3/3 |
| 하루 섭취 | 에너지 **1,075.8 kcal** · 단백질 **43.5 g** |
| 목표 대비 | 에너지 **71.7%** (목표 1,500 kcal) · 단백질 **79.0%** (목표 55 g) |
| 계획 대비 | 에너지 63.4% (계획 1,698 kcal) · 단백질 62.6% (계획 69.4 g) |
| 패턴 | 채소 반찬(나물·볶음)과 깍두기를 남기고, 부드러운 단백질 반찬(달걀찜·두부조림)은 다 먹음 |

에너지가 목표의 75% 미만이므로, 이 수준이 7일 이어지면 "주의"가 된다 ([설계 전 검토](../../pilot-design-review.md) 5절).

## 원본 대비 보강 내용

| 보강 | 근거 |
| --- | --- |
| 한 끼를 3가지에서 **6칸(밥·국·주찬·부찬 2·김치)**으로 늘림. 원본 메뉴와 섭취율은 그대로 두고 국, 부찬 1, 김치를 더함 | 춘천시 사회복지급식관리지원센터 2025년 8월 일반식 표준식단 (93끼 중 92끼가 6가지) |
| 칸마다 **표준 배식량과 에너지·단백질**을 넣어 끼니·하루 섭취량을 계산함 | 섭취량 = 섭취율 × 배식량 영양성분 ([데이터 모델](../../data-model.md) 4절) |
| 발주에 **식사 범주·식사 코드·처방 시작·특이사항** 필드를 둠 | 인천보훈병원 급식정보(공공데이터포털)의 처방 기록 구조 |
| 목표량에 **출처와 시스템 계산값**을 함께 적음 | ESPEN 노인 임상영양 가이드라인, 2025 한국인 영양소 섭취기준 |
| 체중 감소를 **GLIM 기준과 비교**해 적음 | GLIM 5년 업데이트(2025) |
| 기록 상태를 시스템 상태 값(`recorded`, `estimated`)으로 바꿈 | [시스템 구조](../../system-architecture.md) 4·5절 |

배식량과 영양성분은 일반적인 1인분 기준의 **근사 모의값**이다. 팀이 실물 식판을 저울로 재고 식약처 식품영양성분 데이터로 계산한 값으로 바꾼다.

## 더 보강할 것 (제안)

1. **2주 모의 이력** — 경고 규칙(7일 평균, 연속 5일)을 시연하려면 11/14~11/27 기록이 필요하다. 첫날 패턴(목표 대비 70% 안팎)에서 시작해 점점 줄어 50% 이하가 5일 넘게 이어지면 "경고"로 올라가게 설계한다.
2. **주간 체중** — 관찰 기간에 체중을 주 1회 기록하면, 섭취 감소와 체중 변화를 함께 보여 줄 수 있다. GLIM의 체중 감소 기준(6개월 내 5% 초과)에 가까워지는 흐름도 만들 수 있다.
3. **씹기 문제와 식사 형태** — 씹기 불편 기록과 채소 반찬을 남기는 패턴이 이어지므로, 처방 추천에서 다진찬 발주(`diet_code = "일반상식(다진찬)"`)와 정식 삼킴·씹기 평가를 검토하는 흐름을 시연할 수 있다.
4. **판단 불가 칸 1건** — 섭취 추정의 예외 처리를 보여 주려면, 한 끼에 손이 칸을 가린 사례(`occluded`)를 하나 넣는다.
