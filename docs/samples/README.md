**상태**: 팀 제안안 · **작성일**: 2026-11-27 · **갱신**: 2026-11-27 · **모델**: [데이터 모델](../data-model.md)

시연에는 팀 샘플 "NutriSight 가상 환자 10명과 7일 식사 기록 최종본"(11/23~11/29, 210끼)의 10명을 쓴다. ## 시연 날짜 (결정)

시드는 시연일 기준 상대 날짜로 넣는다. 샘플의 11/23~11/29를 시연일 7일 전~하루 전(D-7~D-1)으로 옮기고, 시연일(D)의 배식 계획 하루치를 추가한다. 시연일 끼니는 시연 중에 업로드한다. 그래서 어느 날 시연하거나 리허설을 반복해도 "오늘 업로드 → NS05 주의 전환" 장면이 같게 나온다. 의사 화면의 추이 그래프는 최근 7일 + 오늘을 보여 준다.

| 샘플 날짜 | 시드 날짜 |
| --- | --- |
| 11/23 ~ 11/29 | D-7 ~ D-1 |
| (없음) | D: 배식 계획만 추가, 끼니는 시연 중 업로드 |

체중 미입력 장면은 시연에서 뺀다. 이전 구성(경고 NS07, 주의 NS03 체중 미입력, 정상 NS05)은 이 구성으로 바뀐다. NS07 샘플([ns07/](ns07/README.md))은 데이터 형식 예시로 남긴다.
