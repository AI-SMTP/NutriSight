# 시연 환자 구성 (팀 제안안)

**상태**: 팀 제안안 · **작성일**: 2026-11-27 · **모델**: [데이터 모델](../data-model.md)

시연에 쓸 가상 환자 3명이다. 시연에서 보여 줄 장면을 한 명에 하나씩 나눠 담았다. 모든 환자와 수치는 모의 데이터다.

| 경고 수준 | 환자 | 병실 | 보여 줄 장면 | 샘플 |
| --- | --- | --- | --- | --- |
| 경고 | NS07 · 여 82세 | 302호 | 체중·진료팀 목표가 있는 환자. 채소 반찬을 남기는 패턴과 씹기 불편 → 식사 강화·다진찬(식사 형태 변경) 추천 → 의사의 항목 추가·수정과 확정 | [ns07/](ns07/README.md) |
| 주의 | (작성 예정) | 305호 | 체중 미입력 → 2025 한국인 영양소 섭취기준으로 필요량 계산, 추천 카드의 "확인 필요" 문구 | — |
| 정상 | (작성 예정) | 302호 | 같은 날 미기록 1끼와 금식 1끼 → 미기록은 미기록 수로, 금식은 따로 표시되는 차이 | — |

- 화면 초안의 환자 A·B·C는 이 구성으로 바꾼다. 화면 초안의 환자 B가 맡던 "체중 미입력" 장면은 주의 환자로 옮긴다.
- NS07이 경고까지 가려면 11/14~11/27 2주 모의 이력이 필요하다 ([ns07/README.md](ns07/README.md) "더 보강할 것" 1번).
- 환자 ID는 주의·정상 환자 샘플을 만들 때 정한다.
