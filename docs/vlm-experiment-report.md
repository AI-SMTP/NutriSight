# NutriSight — VLM 실험 보고서

## 1. 목적 및 범위
식전·식후 식판 이미지와 메뉴명, 슬롯 위치를 비교하여 슬롯별 시각적 섭취율(0.0~1.0, 0.1 단위)을 추정한다. 비교가 불가능하면 null과 판단 불가 상태를 반환한다. 실측 중량 및 MAE는 팀 합의에 따라 이번 파일럿의 평가 범위에서 제외한다.

## 2. 실험 환경 및 데이터
- 실제 촬영 식판 2종, 원본 사진 9장. 첫 식판은 식전 1장과 단계별 식후 4장, 신규 식판은 식전 1장과 식후 3장으로 구성했다.
- 각 식후 이미지는 동일 식전 이미지와 비교했다. 동일 이미지 비교를 대조 조건으로 사용했다.
- 총 API 호출 40회: 성공 38회, 실패 2회. 최종 설정 실험은 9회 모두 성공(54개 슬롯 결과).
- JPEG 품질 85, EXIF 방향 보정, RGB 변환, 긴 변 최대 1536px(확대하지 않음)를 기본 조건으로 사용했다.
- 독립 실험 환경과 팀 통합 환경은 분리했다. 팀 환경은 Python 3.12.16, Anthropic 2.14.0, Pillow 13.0.0, Pydantic 2.14.4.

## 3. 프롬프트 개선
| 버전 | 변경 및 관찰 |
|---|---|
| V1 | 초기 시각 비교 지시. 메뉴에 없는 재료명 추정이 관찰됨. |
| V2 | 메뉴명 제약 및 품질 판단 보완. 첫 4회에서 24슬롯 중 22개 수치 반환, 2개 tray_mismatch 판단 불가. 해당 사진 재실행에서는 두 슬롯 모두 90% 반환. |
| V3 | 식판 불일치 판단 기준, 관찰 근거, 수치 앵커, 판단 불가 조건 구체화. 첫 식판 5회에서 30/30 슬롯 수치 반환. 동일 사진은 모두 0%, 단계별 인접 역전 없음. |
| V4 | V3에 5개 예시 추가. V3 대비 28/30 슬롯 동일(93.3%), 평균 절대 차이 0.67%p, 최대 10%p. 입력 토큰 6,571→7,149. |

V3를 선정했다. V4는 출력 토큰과 평균 응답 시간이 감소했지만 총 토큰은 약 7.55% 증가했고, 제한된 표본에서 추가 예시의 뚜렷한 이점이 확인되지 않았다. V3에서도 메뉴 외 재료명 관련 표현이 관찰되어 완전한 방지를 주장하지 않는다.

## 4. 이미지 해상도 비교
동일 식판의 after_03 조건, V3 기준.

| 최대 긴 변 | 입력 토큰 | 1536 대비 평균 절대 추정값 차이 | 최대 차이 |
|---|---:|---:|---:|
| 1536 | 6571 | 기준 | 기준 |
| 1024 | 4023 | 5.00%p | 20%p |
| 768 | 3127 | 3.33%p | 20%p |

입력 토큰은 각각 약 38.8%, 52.4% 감소했다. 그러나 일부 슬롯 추정값이 20%p 달라졌고 대부분의 기존 실험이 1536 조건에서 수행되어 이를 유지했다. 위 차이는 모델 출력 간 차이이며 정확도 지표가 아니다.

## 5. 모델 비교
| 모델 | 호출 | 성공 | 관찰 |
|---|---:|---:|---|
| Haiku 5.5 | 3 | 2 | after_03에서 max_tokens 종료로 응답 검증 실패 |
| Sonnet 5.5 | 기존 V3 5회 | 5 | 동일 사진 0%, 첫 식판 단계별 역전 없음 |
| Opus 5.5 | 4 | 4 | 정상 응답, 공통 조건에서 Sonnet보다 긴 평균 지연 |

공통 동일사진/after_01 조건 평균 지연은 Haiku 약 8.45초, Sonnet 5.62초, Opus 8.50초였다. 표본이 작고 반복 횟수가 제한되므로 모델 정확도 순위가 아니라 응답 안정성과 운영 효율을 기준으로 Sonnet을 선정했다.

## 6. 출력 스키마 비교
| 스키마 | 방식 | 30슬롯 수치 반환 | 평균 총 토큰 | 평균 지연 |
|---|---|---:|---:|---:|
| A | 소비량 정수 0~10 → 비율 변환 | 30 | 7201.8 | 6.22초 |
| B | intake_fraction_est 직접 반환(0.1 단위 enum) | 30 | 7319 | 6.32초 |
| C | 잔량 정수 0~10 → 소비 비율 변환 | 30 | 7156.2 | 6.13초 |

A/B 일치 25/30(83.3%), A/C 22/30(73.3%), B/C 23/30(76.7%). 평균 절대 차이는 각각 1.67, 2.67, 2.33%p, 최대 차이는 모두 10%p였다. C 초기 요청은 BadRequestError로 실패했으며 JSON Schema의 min/max 제약을 제거하고 Python 검증을 유지한 뒤 성공했다. 최초 실패의 상세 원인은 확정하지 않는다. C에서 마지막 단계 슬롯 5의 100→90% 역전이 관찰됐다. B는 팀 공통 타입과 직접 일치하고 첫 식판에서 역전이 관찰되지 않아 선정했다.

## 8. 최종 구성 및 결론
- claude-sonnet-5-5 / V3 / Schema B / 최대 긴 변 1536px / JPEG 85
- 최대 출력 1600토큰, timeout 60초, SDK 자동 재시도 0회, 어댑터 자체 반복 추론 없음.
- 0.0은 의미 있는 시각적 감소 없음, 1.0은 의미 있는 잔량이 거의 없음이며 실제 완전 섭취를 보증하지 않는다.
- 최종 팀 어댑터 프롬프트는 독립 실험 V3 B와 문자열 완전 일치 검증을 통과했다.
- 제한된 두 식판과 조건별 소수 호출로 얻은 탐색적 결과이며 일반화나 임상적 신뢰성을 주장하지 않는다. 실측 중량 및 MAE는 합의된 제외 범위다.
- 독립 실험 원본 로그: `var/intake_eval/experiments.jsonl`, 개발 이력: `var/intake_eval/development-history.txt` (독립 프로젝트 및 백업에 보존). 이 문서는 기존 실험 기록과 대화에서 확인된 결과의 요약이며 원본 로그를 이번 작성 시 다시 집계하지 않았다.
